`pipes.wav` was extracted from approximately 10–12 seconds of the original recording for use by the
Piano Staircase Demo 2 special-event system.

The extracted clip retains the original 48 kHz stereo format and is encoded as 16-bit PCM WAV. Short
fades were added at the edit boundaries.
